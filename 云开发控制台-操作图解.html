云开发控制台 · 操作图解

旧环境（demo- 开头的试用环境）已过期，这是登录失败的根源。 下面从新建环境开始，到登录跑通，一共 5 张图。 建集合、建索引、设权限这些必须你自己在网页上点，我代劳不了。

提醒：界面可能因版本略有差异。位置对不上不要紧，认关键词： 「新建环境」「数据库」「索引管理」「权限设置」「唯一」。

图 1 · 新建环境（旧环境已过期）你来做

在开发者工具点顶部「☁ 云开发」打开，环境列表长这样

  • 1点「新建环境」→ 计费选按量付费（个人有免费额度，这个量级基本花不到钱）→ 环境名随意（比如 plus-one）→ 确定，等半分钟创建完。
  • 2创建完成后，复制新环境的完整环境 ID（点进环境也能看到，形如 plus-one-1a2b3c4d5e）。
  • 3回到开发者工具，打开 miniprogram/utils/config.js， 第 8 行替换成新 ID 并保存：
    const ENV_ID = 'plus-one-1a2b3c4d5e';
旧的过期环境先留着别删，等新环境登录跑通了再删，释放名额。 新环境是全新数据库，旧环境里就算有过数据也不会自动迁过来。

上传在开发者工具的文件树里做（见清单第 6 条），这里只用来确认结果。 环境变量一个都不用配。
  • 1「所有用户不可读写」 —— 必须选这个。
    所有数据访问都走云函数（云函数有管理员权限），客户端不直连数据库。
    留着默认权限的话，别人能直接读写你的数据库，绕过全部账号校验。
  • 2两个函数都显示「部署成功」才算完成。

你的完整勾选清单

  1. 云开发控制台 → 「新建环境」（按量付费）
    ✔ 拿到新环境 ID
  2. 把环境 ID 填进 miniprogram/utils/config.js 第 8 行的 ENV_ID，保存
    ✔ 环境 ID 一字不差
  3. 「数据库」里建 2 个集合：accounts sync_docs
    ✔ 数据库里正好这 2 个
  4. 建 2 个唯一索引：accounts 的 openid； sync_docs 的 userId + key（联合）
    ✔ 属性都是「唯一」
  5. 2 个集合的权限都设为「所有用户不可读写」
    ✔ 权限设置里最后一项被选中
  6. 开发者工具文件树 cloudfunctions 下，右键 auth → 「上传并部署：云端安装依赖」；再对 sync 做一次
    ✔ 控制台「云函数」里两个都显示部署成功（环境变量一个都不用配）
  7. 点「编译」
    ✔ 登录页显示「微信一键登录」按钮 → 点击 → 提示「账号已创建」进入今日页 —— 成了 🎉
    最后自测：新建目标、打卡一次、「我的 → 立即同步」提示已同步。
